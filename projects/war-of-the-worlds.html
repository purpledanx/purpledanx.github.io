Overview

I helped contribute an admin command line system with global and server polls and announcements for the Roblox game War of the Worlds. The system allows staff to manage the game efficiently with real-time server-wide communication tools. The base of the system is made with Cmdr by evara. Everything other than the command line is built from scratch by me.

My contribution

  • Created a global and per-server poll systems from scratch
  • Created an announcement system that broadcasts across active servers
  • Designed the system to be modular and easy for other developers to extend
