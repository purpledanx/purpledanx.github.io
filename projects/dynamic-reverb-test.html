Dynamic Reverb Test

Personal Project

Overview

A personal project that dynamically adjusts the reverb you hear based on the material and size of your environment. Uses raycasting to detect nearby surfaces and their materials and the size of the room.

What I Did

  • Built a raycasting system to detect room size and surrounding materials
  • Mapped material types to reverb presets for realistic audio feedback
  • Created smooth real-time transitions between reverb states
  • Optimized performance so raycasts don't impact gameplay framerate

Tech Used
